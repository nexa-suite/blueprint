# Test strategy

Repository-specific test evidence remains in AS-IS records and independent application repositories. This index does not claim runtime certification.

## Mobile construction profile

Use narrow evidence first: unit tests for ViewModel/action state and mappers;
adapter/contract tests for OpenAPI DTO translation, Problem Details and command
headers; selected integration/UI tests for authorized context, stale/conflict,
retry/unknown-result and manual camera fallback. Device, distribution,
performance and Product Acceptance remain separate evidence gates.
