# Component inventory

Reusable candidates for v1 evidence are Button, Text Field, Action Menu, Segmented Control, Locale Switcher, Status Chip, Tooltip, Toggle, Numeric Stepper, Range Slider, Surface and Logo. Native controls remain preferred for select, checkbox, radio, progress and table semantics until a composite contract earns its complexity.

Component pages may demonstrate additional patterns, but a page specimen is not automatically reusable. The Design Lab public API is the executable inventory boundary.
