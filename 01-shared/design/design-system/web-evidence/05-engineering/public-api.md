# Public API

The public API exports reusable intent: Button, Text Field, Action Menu, Segmented Control, Locale Switcher, Status, Tooltip, Toggle, Logo, Surface, Numeric Stepper and Range Slider. State Sequence, contrast math and documentation frames remain Lab-only. Deep imports are prohibited.
