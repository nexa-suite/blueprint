# Analytics

Every specimen follows Question → Visualization → Text summary → Accessible data/details. Appropriate candidates include KPI, progress ring, donut, horizontal/grouped/stacked bars, line/area trend, sparkline, bullet/target, timeline, status distribution and table fallback, with explicit no-data/loading/error states.

Charts are not decoration. Visualization colors use data roles, not arbitrary semantic danger/success colors, and no library is required until lightweight SVG/CSS evidence proves insufficient.
