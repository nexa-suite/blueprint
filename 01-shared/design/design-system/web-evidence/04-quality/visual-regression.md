# Visual regression

Capture deterministic routes at 1440 and 390, and check overflow at 1024, 768 and 320. Include selected, focus, error, loading, disabled and open states. Record route, viewport, state, artifact, test path and source SHA. Visual regression is evidence for review, not a substitute for human judgment.
