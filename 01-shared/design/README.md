# Shared Design

Nexa Design System is shared concern, not Web-only documentation.

Source-of-truth relationship:

- **Blueprint**: normative product/design governance, adoption contract and cross-surface policy.
- **Design Lab**: executable visual source and validation companion at [github.com/nexa-suite/design-lab](https://github.com/nexa-suite/design-lab).
- **Applications**: consume public boundary and preserve accessibility, responsive and interaction contracts.
