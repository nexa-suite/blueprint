# Adoption and customer success

**Status:** `PROPOSED` / `RESEARCHING`.

## Candidate assisted-adoption process

Contact -> qualification -> discovery -> demo -> agreement -> assisted
onboarding -> configuration -> controlled data import -> role-based training
-> controlled go-live -> 30/60/90-day review.

This is a commercial/adoption hypothesis, not an implemented workflow, API
contract, Website commitment or Product Acceptance result.

## Research boundary

Measure activation, time-to-value, role adoption, data quality, exception
handling and retention only after definitions, consent, baselines and source
systems are agreed. Do not infer adoption from a release tag, a green build or
the existence of a documentation flow.
