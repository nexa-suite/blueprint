# Spacing and layout

Use the shared spacing scale and focused aliases for control padding, panel/card padding, control gap and surface gap. Layout is intrinsic first: grids use minmax, content can reflow, and wide data scrolls locally rather than forcing page overflow.

Page gutters, section rhythm, internal card insets and divider ownership must be consistent at 1440, 1024, 768, 390 and 320 widths. Do not hide spacing defects with negative margins.
