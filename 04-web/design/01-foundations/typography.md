# Typography

Use Plus Jakarta Sans for display/heading hierarchy, Inter for body and controls, and a system mono stack for identifiers, evidence labels and technical values. Hierarchy is created with scale, weight, line-height and measure before decoration.

Labels remain readable at 200% text size. Uppercase kickers are supporting metadata, not a substitute for a heading. Do not introduce another font direction without a baseline decision.
