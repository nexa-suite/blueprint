# Iconography

PrimeIcons are the canonical web icon set for v1. Icons add semantic value, keep a consistent optical size and never replace an accessible label. The icon explorer and pinned local asset pipeline are executable evidence in Design Lab.

Do not mix Material icon fonts, remote icon assets or decorative icon noise into a product action. Status icons supplement text and shape; color alone is insufficient.
