# Dispatch and delivery

Dispatch Board evidence includes empty, selected, source/destination, completed, warning, critical and blocked cards. An accessible command path is equivalent to pointer movement; reduced motion retains source, destination and completion meaning without spatial animation.

Delivery/POD evidence names destination, receiver, time and attachment state. Driver/Mobile execution is runway/experimental, not a v1 implementation claim.
