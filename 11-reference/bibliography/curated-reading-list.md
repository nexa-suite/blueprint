# Curated reading list

The list is a research index, not a license or an architectural decision.

| Topic | Safe public starting point | Nexa use |
|---|---|---|
| Architecture | [C4 model](https://c4model.com/) and [Structurizr DSL](https://docs.structurizr.com/dsl/language) | Preserve L1/L2 semantics and validate source |
| Domain discovery | [Domain-Driven Design community](https://www.domainlanguage.com/ddd/) | Prepare discovery; do not infer DDD outputs |
| Accessibility | [WCAG 2.2](https://www.w3.org/TR/WCAG22/) | Future UI acceptance criteria |
| Design systems | [Material 3](https://m3.material.io/) and [Design Tokens Community Group](https://www.w3.org/community/design-tokens/) | Future system foundations |
| Security | [OWASP Application Security Verification Standard](https://owasp.org/www-project-application-security-verification-standard/) | Future security architecture inputs |
| Reliability | [OpenTelemetry documentation](https://opentelemetry.io/docs/) | Future observability direction |

Private commercial references can inform individual decisions locally, subject to license, but their files and identifying local paths do not belong in Blueprint.
