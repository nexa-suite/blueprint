# Mobile assumptions

No assumptions are validated in this wave. Candidate areas for research:

- Field and warehouse actors need quick, contextual work without reproducing
  full Platform administration.
- Driver delivery execution and Warehouse core workflows justify selective
  offline operation.
- Buyer frequent ordering, delivery confirmation, push and document/payment
  access justify a Mobile-primary surface.
- Dispatch Handoff evidence and Buyer/Driver discrepancy require distinct facts.
- Push, scan, location and secure local storage are integration/application
  concerns, not new domain boundaries.

Validate participant, frequency, failure cost, connectivity and policy before
creating Mobile User Stories.
