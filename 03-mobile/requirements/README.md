# Mobile Requirements

The canonical Product catalog contains exactly 73 functional stories,
`MOB-US-001..073`. All 73 belong to the course-end **Nexa Mobile V1 Product
Generation planning envelope**. The former 28/35/9/1 split is retained only as
historical planning provenance; it is no longer current Product release
nomenclature.

lifecycle, implementation, verification and acceptance are independent
dimensions. The Mobile report's academic projection contains 97 PBIs and does
not redefine this Product catalog. Needfinding problem/task evidence is
available, while solution validation and Product Acceptance remain open.

Story Points, Sprint assignment, milestone mapping and evidence links live in
