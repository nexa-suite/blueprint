# Mobile local storage

Status: `OPEN / DISCOVERY`. The logical local models are proposed only.

Allowed candidates: secure session reference, active context reference,
refreshable projections, local drafts, evidence upload queue, synchronization
cursor and conflict metadata. Forbidden: passwords, bearer tokens, provider
secrets, card/payment credentials and authoritative inventory/order/payment/
Delivery state. Encryption, retention, wipe/revocation and platform keystore
selection require SPIKE-004 and security acceptance.
