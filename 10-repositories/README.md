# Repositories

## Purpose

Provide a documentation-only index of Nexa's independent application repositories and their evidence boundaries for the future Blueprint repository.

## Authoritative content

- [Repository map](repository-map.md) — current remote baseline references and local checkout caveats.
- Repository-owned README files under the independent checkouts — implementation-specific facts.

## Current status

INDEX. API, Platform, Portal and Website are active independent repositories; Mobile is runway. The workspace root is not a Git repository. Local active clones are not Blueprint content.

## Expected artifacts

Repository URLs, responsibility, technology, branch/SHA evidence where verified, release references and explicit local/publication boundaries.

## What must not live here

Copied or moved application source, Git submodules, secrets, generated build/runtime data, or claims that implementation folders are Bounded Contexts.
