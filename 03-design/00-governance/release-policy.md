# Design release policy

Design-system releases are versioned baselines, not a tag for every experiment. A release candidate may publish evidence and known gaps; a v1 release requires the deterministic gates, responsive/visual evidence, human design review and accessibility handoff recorded in the release pack.

Design Lab `v1.0.0` established executable scope. Current `v1.0.1` is a metadata-correction patch over that baseline, not a domain or production contract. The current local `main` evidence snapshot is `d27e158569211a3afec171b1c9606f06906fc99a`.

Blueprint remains normative for design-system governance and adoption. Design Lab evidence may mark foundations/components frozen only where its own release evidence does; it does not close Product, domain, API, authentication, payment, mobile or production decisions.
