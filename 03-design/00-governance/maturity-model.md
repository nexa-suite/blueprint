# Maturity model

| Status | Meaning | Required evidence |
|---|---|---|
| FROZEN | Human-approved visual direction; casual drift is prohibited. | Source decision, component states, accessibility and regression evidence. |
| CANDIDATE | Reviewable design-system or composition proposal. | Purpose, states, live specimen, API/content notes and open owner. |
| EXPERIMENTAL | Bounded investigation with no adoption promise. | Hypothesis, scope, exit criteria and explicit non-production label. |
| DEFERRED | Intentionally outside v1. | Reason, dependency and revisit condition. |
| DEPRECATED | Retired direction retained only for migration/provenance. | Replacement and removal boundary. |

FROZEN is not production certification. A passing automated gate is not human design or assistive-technology approval.
