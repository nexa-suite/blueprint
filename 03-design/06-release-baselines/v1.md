# Nexa Design System v1 release baseline

This baseline preserves the accepted Nexa visual foundation: canonical logo, Plus Jakarta Sans / Inter / mono hierarchy, blue/slate identity, light appearance, Sidebar, Text Field, Action Menu, keycaps, semantic geometry and restrained elevation.

## Included

Foundations, reusable web candidates, focused product-safe patterns, quality evidence, Angular public API, token generation, icon pipeline, responsive checks and adoption documentation.

## Classification

Reusable candidates are CANDIDATE until human review closes them. Authentication, Analytics, Dispatch, catalog, request, order, payment, delivery and map pages are composition evidence. Mobile/Driver, IoT, provider-specific integrations, backend authentication, anonymous registration, final legal policy and production domain transitions are RUNWAY, EXPERIMENTAL or DEFERRED.

## Release gate

The v0.10 Design Lab release candidate is the executable companion. It must pass deterministic architecture, token, color, icon, documentation, public API, contrast, test and build gates, then record browser/responsive/reduced-motion/increased-contrast and human review status. It is not a final v1 package and must not be merged into production application repositories from this baseline alone.
