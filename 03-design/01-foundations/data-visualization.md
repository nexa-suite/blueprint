# Data visualization

Use the lightest visual that answers a stated question: metric/KPI, progress ring, donut, bar, grouped/stacked distribution, line/area trend, sparkline, bullet/target, timeline or status distribution. Each visual includes a text summary and accessible data/details fallback.

Visualization roles are distinct from semantic status roles. Do not add charts for decoration or introduce a chart library before the Lab demonstrates a need.
