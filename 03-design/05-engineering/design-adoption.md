# Design adoption and handoff

An adoption record names Blueprint baseline, Design Lab source SHA, public API, token version, affected surface, maturity, deterministic gates, visual artifacts and human design/accessibility decision. Figma/code mapping is not a primary destination without a real shared library; the handoff is a traceable decision, not a decorative page.
