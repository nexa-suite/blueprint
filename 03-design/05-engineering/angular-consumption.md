# Angular consumption

Angular applications consume reusable candidates through a stable public entrypoint. Route features own page content and lazy-load actual feature code. Documentation and Lab modules are not imported by the design-system library. Strict templates, native semantics and signal-first local state are the implementation evidence baseline.
