# Component maturity

Sidebar, Text Field, Action Menu, Logo, typography hierarchy, light appearance and keycap language are frozen directions. The remaining reusable controls are candidates until human visual, content, keyboard and assistive-technology review closes them. Experimental composite controls remain bounded investigations.

Maturity is per component and per behavior. A frozen visual direction does not imply a production package, and an automated unit test does not imply accessibility certification.
