# Superseded pre-freeze Web story baseline

The former US-001 through US-037 register was the accepted pre-freeze
baseline. The current Web catalog is now the namespaced 133-story catalog,
with WEB-US-001 through WEB-US-133 grouped into 15 Epics.

The old identifiers remain historical context in Git history and must not be
counted as current catalog items. They are not silently mapped to new stories;
future refinement may establish explicit KEEP, REFINE, SPLIT, MERGE,
SUPERSEDE or DROP decisions with provenance.
